# Generated gameplay artwork

These new sprite sheets were generated with the built-in imagegen tool, preserving the repository's existing completed-wonder images. Output PNG alpha is retained. Source prompts are recorded for reproducibility; generated outputs can vary between runs.

This index links the complete prompt records: the four wonders below; [the three central wonders](generated-art-central.md); [Colossus of Rhodes, Segovia and Pont du Gard](generated-art-military.md); and [all eleven military unit sheets](generated-art-units.md). Ay Khanum and its construction sheet were removed at the user's request. Runtime verification is recorded separately in the implementation audits.

## Wonders: Pyramid, Dodona, Stonehenge, Pergamon

### great_pyramid

- Output: `assets/images/wonders/construction/great_pyramid.png`
- Reference: `assets/images/wonders/great_pyramid.png`
- Mode: built-in imagegen, transparent background, four-frame 2×2 sheet.
- Visual review: identity, construction scaffolds, consistent isometric camera and complete four-cell layout checked in the generated output. Runtime animation review is tracked separately.

Prompt:

> Use case: stylized-concept. Asset type: transparent isometric game sprite animation sheet. Input image is the completed Great Pyramid of Giza, used as the identity, camera and painting-style reference. Create a NEW square 2x2 sprite sheet with EXACTLY FOUR equal square cells, row-major frames of a looping construction animation of this same wonder at a single half-built construction stage. Recognizable large golden sandstone pyramid but only the lower two thirds have been built, with a flat unfinished summit, ramps, stacked blocks and slender wooden scaffolds on the sides. Preserve the reference's small rectangular foundation and front enclosure walls. Match the reference's clean illustrated beveled stone, warm ochre palette, three-quarter elevated isometric camera and top-left light. Each cell has the EXACT SAME static structure, identical scale, footprint, orientation and camera, centered with comfortable transparent margins. Animate only tiny builders, their tool poses, rope pulling and carrying stones across the four frames; keep the half-built wonder shape unchanged so the sequence loops. All four frames must show clearly identifiable wonder-specific construction, not a generic building or generic scaffold overlay. The four quadrants must not touch or overlap; keep each whole sprite strictly inside its quadrant. Actual transparent alpha background, no sky or scenery outside the small foundation. No text, numbers, labels, borders, gridlines, watermarks or decorative frame. Produce a crisp game-ready PNG sheet.
