# README gameplay claim audit

This is a traceability audit of the current README, not a claim that every feature has been exercised through a native window. Each row covers the listed README claims, their normal player entry point, the authoritative implementation, and available verification. It also records the user's later **ten-wonder** override.

**Evidence terminology:** “wired” means the displayed control calls the engine or reads the authoritative campaign state. Named tests below are concrete regression coverage, not proof of an entire playthrough. The 24 renderer-independent politics tests were run successfully during this audit. The final integrated test, Clippy, formatting, wasm and packaging results are recorded in [verification.md](verification.md). Native visual review remains pending. Headless layout tests measure bounds and render real widgets; they do not prove that artwork or animations look good.

Test references use `tests/unit/<topic>.rs`, where private unit coverage is retained through `#[cfg(test)]` path hooks. No claim below relies on the old shell-only resource simulation as proof of the new campaign rules.
